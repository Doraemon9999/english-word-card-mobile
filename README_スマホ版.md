# 英単語カード スマホ版

PC版の機能を引き継ぎ、iPhone・iPad・Androidで使いやすいPWA（ホーム画面へ追加できるWebアプリ）として再構成した版です。

## 主な機能

- 2,027語の英単語カード
- 英語→日本語、日本語→英語の切り替え
- 「もう一度」にした単語だけの復習
- 英単語の端末音声による発音
- 当日の回答数・正解率の端末内保存
- 10問・20問のランダムテスト作成
- 問題PDF・解答PDFの保存
- Google Apps Scriptを使ったPDFメール送信（任意設定）
- 初回表示後のオフライン利用

## スマートフォンで使うまで

このアプリは、ファイルをスマートフォンへコピーするだけでなく、HTTPSで公開してブラウザから開く必要があります。GitHub Pagesなどの静的Webホスティングへ、このフォルダ内のファイルとサブフォルダを構成を変えずに配置してください。

公開後のURLをスマートフォンで開き、次の操作を行います。

### iPhone / iPad

1. Safariで公開URLを開く。
2. 共有ボタンを押す。
3. 「ホーム画面に追加」を選ぶ。

### Android

1. Chromeで公開URLを開く。
2. 右上のメニューを開く。
3. 「アプリをインストール」または「ホーム画面に追加」を選ぶ。

## PCでの表示確認

フォルダ内で静的Webサーバーを起動し、ブラウザの開発者ツールでスマートフォン表示へ切り替えて確認できます。`index.html`を直接ダブルクリックした場合は、オフライン保存やPDF用フォント読み込みなど一部機能が動作しません。

## 保存データ

復習リスト、当日の回答数・正解率、メール設定は、利用中の端末とブラウザの `localStorage` に保存されます。別端末への自動同期は行いません。

## メール送信

`gas/Code.gs` をGoogle Apps Scriptへ設定し、アプリの「設定」でウェブアプリURL・共有キー・送信先を保存すると利用できます。メール送信だけはインターネット接続が必要です。
